ОЦЕНКА КАЧЕСТВА КОДА И НАДЕЖНОСТИ ПРОГРАММНОГО МОДУЛЯ
Программный модуль учёта заявок на ремонт автомобилей
Версия 2.0 (с доработками для модуля 3)
Дата оценки: 12.03.2026

1. ПОЛНОТА ОБРАБОТКИ ОШИБОЧНЫХ ДАННЫХ
   - При авторизации проверяется заполнение полей логина и пароля,
     выводится сообщение об ошибке при неверных данных.
   - При добавлении/редактировании заявки выполняется валидация:
     обязательные поля (дата, тип авто, модель, описание) проверяются,
     формат даты контролируется (ГГГГ-ММ-ДД).
   - При работе с файловой системой (резервное копирование, генерация QR-кода)
     перехватываются исключения PermissionError, FileNotFoundError.
   - Все исключения БД обрабатываются с выводом информативных сообщений.
   Оценка: 5/5

2. НАЛИЧИЕ ТЕСТОВ ДЛЯ ПРОВЕРКИ ДОПУСТИМЫХ ЗНАЧЕНИЙ
   - Проведено ручное тестирование по следующим сценариям:
     * Аутентификация (правильный/неправильный логин/пароль)
     * Добавление новой заявки (с заполнением всех полей)
     * Редактирование существующей заявки
     * Генерация QR-кода
     * Продление срока заявки менеджером по качеству
     * Резервное копирование базы данных
   - Все тесты выполнены успешно, протокол прилагается.
   Оценка: 4/5 (отсутствуют автоматические модульные тесты)

3. НАЛИЧИЕ СРЕДСТВ КОНТРОЛЯ КОРРЕКТНОСТИ ВХОДНЫХ ДАННЫХ
   - Ввод даты контролируется (проверка формата, невозможность ввести
     несуществующую дату через календарь).
   - Выпадающие списки (тип авто, статус, механик) исключают неверный ввод.
   - Поля, обязательные для заполнения, проверяются перед сохранением.
   Оценка: 5/5

4. НАЛИЧИЕ СРЕДСТВ ВОССТАНОВЛЕНИЯ ПРИ СБОЯХ
   - Реализовано резервное копирование базы данных через меню «Файл».
   - База данных SQLite работает в режиме WAL, обеспечивающем целостность.
   - При следующем запуске после сбоя программа проверяет целостность БД.
   Оценка: 4/5 (нет автоматического восстановления)

5. НАЛИЧИЕ КОММЕНТАРИЕВ В КОДЕ
   - Код содержит docstring для всех классов и публичных методов.
   - Сложные участки (например, расчёт статистики, генерация QR-кода)
     снабжены пояснительными комментариями.
   - Комментарии оформлены на русском языке, объясняют нетривиальные моменты.
   Оценка: 5/5

6. НАЛИЧИЕ ПРОВЕРКИ КОРРЕКТНОСТИ ПЕРЕДАВАЕМЫХ ДАННЫХ
   - Все SQL-запросы используют параметризованные запросы (через ?),
     что исключает SQL-инъекции.
   - При передаче ID заявки/пользователя выполняется проверка типа и диапазона.
   Оценка: 5/5

7. НАЛИЧИЕ ОПИСАНИЙ ОСНОВНЫХ ФУНКЦИЙ
   - Для каждой ключевой функции (get_completed_requests_count,
     generate_qr, backup_database и др.) составлено описание в docstring.
   - Описаны назначение, параметры, возвращаемые значения.
   Оценка: 5/5

ИТОГОВАЯ ОЦЕНКА: 33/35 (94.3%) – высокое качество и надёжность.
