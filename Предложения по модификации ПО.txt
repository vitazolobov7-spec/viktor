ПРЕДЛОЖЕНИЯ ПО МОДИФИКАЦИИ ПРОГРАММНОГО ОБЕСПЕЧЕНИЯ
Программный модуль учёта заявок на ремонт автомобилей
Дата: 12.03.2026

На основе дополнения к техническому заданию (Прил_3) и анализа
существующего функционала предлагаются следующие модификации:

1. ВВЕДЕНИЕ РОЛИ «МЕНЕДЖЕР ПО КАЧЕСТВУ»
   - Наделить правами: привлечение автомехаников к выполнению ремонта,
     продление срока выполнения заявки по согласованию с клиентом.
   - Добавить соответствующие пункты меню и кнопки в интерфейсе.
   Статус: РЕАЛИЗОВАНО.

2. ГЕНЕРАЦИЯ QR-КОДА ДЛЯ ОЦЕНКИ РАБОТЫ
   - При завершении заявки формируется QR-код со ссылкой на форму
     Google Forms (https://forms.gle/...).
   - QR-код сохраняется в папку qr_codes/ и может быть распечатан.
   Статус: РЕАЛИЗОВАНО.

3. РАСШИРЕНИЕ ФУНКЦИОНАЛА ОТЧЁТОВ
   - Добавить отчёт по качеству: средняя оценка, количество отзывов,
     распределение оценок (требует доработки таблицы Оценка_качества).
   - Добавить отчёт по загрузке механиков.
   Статус: ПРЕДЛОЖЕНО (может быть реализовано в версии 3.0).

4. УЛУЧШЕНИЕ ОБРАБОТКИ ОШИБОК И ВАЛИДАЦИИ
   - Добавить проверку номера телефона по маске (регулярное выражение).
   - Реализовать календарь для выбора даты вместо ручного ввода.
   - Добавить подтверждение при удалении заявки.
   Статус: ЧАСТИЧНО РЕАЛИЗОВАНО (дата проверяется, календарь добавлен).

5. ИНТЕГРАЦИЯ С ВНЕШНИМИ СЕРВИСАМИ
   - Отправка уведомлений клиенту по SMS или email при изменении
     статуса заявки.
   - Возможность интеграции с Telegram-ботом для уведомлений.
   Статус: ПРЕДЛОЖЕНО (перспективное развитие).

6. ДОБАВЛЕНИЕ НОВЫХ СТАТУСОВ ЗАЯВОК
   - «Ожидание запчастей» – уже реализован.
   - «Согласование с клиентом» – предложение добавить промежуточный статус
     для заявок, требующих уточнения.
   Статус: ПРЕДЛОЖЕНО.

7. УЛУЧШЕНИЕ ИНТЕРФЕЙСА
   - Добавить тёмную тему оформления.
   - Реализовать возможность изменения размера шрифта.
   Статус: ПРЕДЛОЖЕНО.

ЗАКЛЮЧЕНИЕ: основные требования заказчика (роль менеджера по качеству,
генерация QR-кода) реализованы полностью. Остальные предложения могут
быть внедрены в следующих версиях продукта.
