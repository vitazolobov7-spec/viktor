Аннотация
---------
Настоящий документ содержит сведения, необходимые системному программисту
для установки, настройки, администрирования и модификации программного модуля
учёта заявок на ремонт автомобилей (далее – ПМ «Автосервис»).

1. НАЗНАЧЕНИЕ И УСЛОВИЯ ПРИМЕНЕНИЯ ПРОГРАММЫ
1.1. ПМ «Автосервис» предназначен для автоматизации учёта и обработки заявок
на ремонт автомобилей в автосервисе.
1.2. Программа функционирует под управлением ОС семейства Windows (7/10/11).
1.3. Для работы программы требуется установленная платформа Python версии 3.9
или выше, а также дополнительные библиотеки, перечисленные в разделе 4.

2. УСЛОВИЯ ВЫПОЛНЕНИЯ ПРОГРАММЫ
2.1. Минимальные технические требования:
    - процессор с тактовой частотой от 1,5 ГГц;
    - оперативная память не менее 2 ГБ;
    - свободное дисковое пространство не менее 500 МБ.
2.2. Программа использует встроенную СУБД SQLite, не требующую отдельной установки.

3. СОСТАВ ТЕХНИЧЕСКИХ СРЕДСТВ
3.1. Для работы программы необходим компьютер с установленной ОС Windows и
наличием прав администратора для установки дополнительных компонентов.
3.2. Рекомендуется наличие принтера или сканера для печати/генерации QR-кодов
(опционально).

4. СТРУКТУРА ПРОГРАММЫ
4.1. Программный модуль состоит из следующих компонентов:
    - main.py – главный исполняемый файл;
    - qr_generator.py – модуль генерации QR-кодов;
    - requirements.txt – список зависимостей Python;
    - autoservice.db – файл базы данных SQLite (создаётся автоматически);
    - backups/ – папка для резервных копий;
    - qr_codes/ – папка для сохранения сгенерированных QR-кодов.
4.2. Логика работы построена на событийно-ориентированном подходе с
использованием библиотеки Tkinter.

5. НАСТРОЙКА ПРОГРАММЫ
5.1. Установка зависимостей:
    - открыть командную строку в папке с программой;
    - выполнить команду: pip install -r requirements.txt
5.2. Конфигурационные параметры:
    - ссылка на форму обратной связи задаётся в файле qr_generator.py
      (переменная FEEDBACK_URL).
    - при необходимости можно изменить название базы данных в файле main.py
      (параметр db_name в классе DatabaseManager).
5.3. Для настройки прав доступа используется встроенный механизм ролей.
    Роли и пользователи хранятся в таблице Пользователи базы данных.

6. ПРОВЕРКА РАБОТОСПОСОБНОСТИ
6.1. Запустить программу двойным щелчком по файлу main.py или командой
    python main.py в консоли.
6.2. В появившемся окне авторизации ввести учётные данные:
    - Менеджер: login1 / pass1
    - Оператор: login4 / pass4
    - Автомеханик: login2 / pass2
    - Заказчик: login11 / pass11
    - Менеджер по качеству: quality_mgr / pass123
6.3. Убедиться, что главное окно открывается без ошибок, отображается список
    заявок, доступны функции согласно роли.

7. ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ
7.1. Генерация QR-кода для оценки качества работ.
    При нажатии кнопки «QR-код» в карточке заявки создаётся QR-код,
    содержащий ссылку на форму Google Forms. Изображение сохраняется в папку
    qr_codes/ с именем request_<ID>.png.
7.2. Резервное копирование базы данных осуществляется через меню «Файл» →
    «Резервное копирование». Копия сохраняется в папку backups/ с датой и
    временем в имени файла.
7.3. Продление срока заявки доступно для роли «Менеджер по качеству».

8. СООБЩЕНИЯ ОПЕРАТОРУ
8.1. Все ошибки и предупреждения выводятся в виде диалоговых окон с
    соответствующими иконками (информация, предупреждение, ошибка).
8.2. В случае сбоя оборудования (например, отсутствие прав на запись)
    программа выводит сообщение с описанием причины и предлагает выбрать
    другое место для сохранения.

9. МОДИФИКАЦИЯ ПРОГРАММЫ
9.1. Добавление новых ролей:
    - внести запись в таблицу Пользователи с новой ролью;
    - при необходимости расширить логику доступа в файле main.py,
      добавив проверки прав в соответствующих методах.
9.2. Изменение формы оценки качества:
    - ссылка на Google Forms задаётся в переменной FEEDBACK_URL в модуле
      qr_generator.py. Для изменения формы достаточно заменить эту ссылку.
9.3. Добавление новых полей в заявку:
    - изменить структуру таблицы Заявки в методе create_database();
    - обновить методы edit_request(), add_request_for_customer/staff()
      для работы с новыми полями.
9.4. Подробное описание всех функций API и классов приведено в документации
    к исходному коду (комментарии в формате docstring).
